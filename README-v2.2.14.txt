RedCode 官網 shop v2.2.14 —— 老闆專用更新說明
==============================================

今次改咗 2 樣嘢，都係圍繞直播：

(1) 推播撳入去彈唔到 Facebook app —— 已修
    你實測：網站嘅「立即入直播」金掣彈到 app 選擇器，
    但推播訊息撳入去就冇彈。
    病因：推播會先去一版「跳板頁」再試開 app，
    舊版跳板頁第一招用咗得 Chrome 先識嘅 intent:// 深鏈；
    你部機（同好多客人嘅瀏覽器）唔識呢招 → 靜靜雞食咗，
    等兩秒半就直接去咗 Facebook 網頁版，全程冇彈 app。
    修正：跳板頁第一招改用同網站金掣完全一樣嘅 fb:// 深鏈
    （你部機實證彈到嗰招），第二招先補 Chrome 專用 intent://；
    真係兩招都冇反應（多數係冇裝 app），5 秒後先落網頁版。
    跳板頁嘅金掣亦換咗做 fb:// 深鏈——就算瀏覽器擋自動跳，
    客人撳金掣都一定彈到 app，掣下面仲有條
    「未裝 Facebook？直接開網頁版」細字連結做後備。
    注意：改動只影響今後新發嘅推播，舊訊息唔會變。

(2) 直播回顧／直播專區有真預覽圖
    之前十場回顧都係同一款設計圖，因為舊版攞縮圖嗰個
    Facebook 官方位對影片淨係回通用灰圖（等於冇）。
    而家伺服器會直接摷每條片播放器入面嘅真縮圖
    （scontent CDN），客人部機直載，每場都睇到當場真畫面。
    伺服器摷唔到嗰場先跌落返原本嘅設計圖，唔會爛相。

順帶講埋你部機睇唔到直播影片（第 2 部機睇到）嗰單：
    你傳嚟嘅截圖見到部機其實播到緊（49 人睇緊嗰版）。
    如果主用嗰部機間中播唔到，多數係個瀏覽器擋咗
    Facebook 嵌入播放器（第三方 cookie／追蹤保護），
    用返第 2 部機同款瀏覽器，或者撳「放大睇／立即入直播」
    去 FB app 睇就穩陣。網站呢邊每個播放器都保留咗
    「去 Facebook 睇」出路，客人唔會卡住。

點樣部署
--------
1. GitHub 倉用網頁上傳成個 zip，解壓覆蓋（或按以往流程）。
2. Render 會自動 build，約 3–13 分鐘，等佢轉綠。
3. 驗收重點：
   a) 喺後台發一場測試推播，電話撳訊息 → 應該直接彈 FB app／選擇器；
   b) 直播回顧每場應該見到唔同嘅真預覽圖。
