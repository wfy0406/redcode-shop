① 推播跳板 v3（live-go-v3.html）—— Samsung/Chrome 彈窗被扯走嘅真相
------------------------------------------------------------
【病因】
老闆你部 Samsung 見到「要開啟第二個 APP」個系統窗，閃得好快、未撳就跳咗
去網頁版 —— 原因係：Android 系統彈「開啟應用程式」窗嗰陣，**頁面本身仲係
睇得見（唔算隱藏）**，所以舊版跳板嘅「X 秒後自動去網頁版」timer 照樣行，
時間一到就扯你走，順便將個系統窗扯埋。第二輪自動深連結都會踩走個窗。

【醫法（v3）】
- 頁面一「失焦」（blur）＝ 系統窗彈咗 / Facebook App 開咗 →
  **即時殺晒全部 timer**，個窗任你慢慢撳，頁面唔會再扯你走。
- 每一次延遲動作（自動轉網頁、第二輪深連結）都先檢查：
  系統窗彈過未？頁面隱藏咗未？係就唔郁。
- 如果你撳「取消」唔入 App，頁面返返嚟 8 秒後先自動去網頁版
  （唔會即刻彈走，畀時間你再撳金掣）。
- 檔名又換咗（live-go-v3.html）：public/ 嘅檔冇 hash，舊檔名會被
  瀏覽器 cache 屈住用舊版，所以每次改版必換名。舊檔（live-go.html /
  live-go-v2.html）留咗做轉址殼，舊推播連結唔會死。

【流程（Android 同 iPhone 一樣）】
入到跳板頁 → 自動試開 Facebook App（1.2 秒內試兩次）→
見到「開啟應用程式」就撳開啟 → 冇彈窗就撳金掣（或撳頁面任何位）→
6 秒內乜都冇發生先自動落網頁版。

【測試方法（一定要用新 URL）】
1. 部署之後，喺手機瀏覽器直接打：
   https://redcode.red/live-go-v3.html?u=https%3A%2F%2Fwww.facebook.com%2Fwatch%2F%3Fv%3D28610528795252808
2. 預期：見到金掣頁，系統彈「開啟應用程式」/ 直接入 Facebook App；
   個窗**唔會再閃走**。
3. 之後喺官網後台發一個測試推播，撳通知 → 應該同上。

※ Chrome 講明：瀏覽器規定「冇人撳嘢就自動彈 App」係會被擋嘅（全世界
網站一樣），所以跳板做咗「自動試 → 撳任何位再試 → 6 秒落網頁版」三段式，
呢個已經係瀏覽器規則下做到嘅極限。

② iPhone 收通知 —— Apple 規定 + 靚圖教學（30 秒）
------------------------------------------------------------
【點解一定要「加至主畫面」？】
呢個係 **Apple 嘅硬性規定，全世界所有網站都一樣**，唔係我哋寫得唔好：
iPhone 由 iOS 16.4 開始，網站推播通知**只限「加咗落主畫面」嘅網站 App**
先收得到；Safari 分頁入面根本冇通知功能（佢連「允許通知」個掣都唔會彈）。
冇任何程式方法繞得過 —— WhatsApp Web、YouTube、所有銀行網站全部一樣。

【所以今次做咗】
- 主頁「🔔 通知我開播」同會員中心，iPhone 一撳就彈**圖文教學**：
  3 張跟 RedCode 主題畫嘅步驟圖（分享掣 → 加至主畫面 → 主畫面圖示開返），
  左右碌睇晒 3 步，30 秒搞掂。
- 跟完步驟，由主畫面圖示入返嚟，撳「我加咗啦，繼續設定通知」→
  **即刻彈「允許通知」**，之後次次開播自動收推播，一勞永逸。
- 如果佢未加就撳繼續，系統會提示「仲係偵測唔到主畫面版本」，唔會死loop。
- Android 客完全唔受影響，照舊一撳「允許通知」就得。

③ 直播回顧順序 —— 官網後台 + WMS 官網中心都改得
------------------------------------------------------------
- 官網後台「直播推播」面板：每場已完結嘅回顧，旁邊多咗 **↑ ↓** 兩個金圈掣，
  撳一下就移前/移後一級。
- WMS 官網中心「直播推播」：同樣有 **↑ 移前 / ↓ 移後** 掣。
- 兩邊改嘅係同一份順序，前台「直播回顧」即刻跟住排。
- 仲喺「正在直播」或者未夠 90 分鐘嘅場次唔會畀你調（避免亂咁）。

※ 直播回顧真預覽圖（v2.2.14 起做咗）要**部署咗先見到**：伺服器會自動
去 Facebook 逐場拎真縮圖。如果個別場拎唔到（FB 冇公開縮圖），會沿用
封面相；官網後台「試播連結」嗰度會話你知邊場拎唔到同埋原因。

④ 部署 + 驗收
------------------------------------------------------------
【部署】（同以往一樣）
1. 將 zip 解壓，全個資料夾用 GitHub 網頁上傳覆蓋 repo（或拖入 GitHub
   Desktop），push 之後 Render 會自動 build。
2. 資料庫新欄位（replayOrder）喺開機時自動加，唔使落指令。
3. JWT_SECRET / VAPID 等環境變數**唔使郁**。

【驗收清單】
□ Render deploy 完成，網站開到。
□ 手機打 live-go-v3.html 測試連結（上面①），系統窗唔再閃走。
□ 發測試推播，撳通知入到 Facebook App。
□ iPhone：主頁撳「🔔 通知我開播」見到 3 張教學圖；跟住做，
  主畫面入返嚟撳繼續 → 彈「允許通知」。
□ 官網後台直播推播：↑↓ 調順序，前台直播回顧跟住變。
□ WMS 官網中心：↑ 移前 / ↓ 移後 一樣 work。
□ 直播回顧每場開始逐漸出現唔同嘅真預覽圖（拎圖要時間，唔使急）。
