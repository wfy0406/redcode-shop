------------------------------------------------------------
① iPhone 推播入 App 去咗首頁嘅真相
------------------------------------------------------------
【病因】
推播本身係帶住你條片嘅地址嘅，冇甩漏。問題出喺跳板頁將地址「翻譯」畀
Facebook App 嘅方法：舊版將地址成串編碼咗（https%3A%2F%2F...），
**Facebook iOS App 解唔返做網址**，當咗佢做「普通開 App」→ 就落咗首頁。
（Android 冇呢個問題，所以 Android 嗰邊原封不動。）

【醫法（跳板頁 v4，live-go-v4.html）】
- iPhone 嘅地址改用 iOS 讀得明嘅寫法 → 開 App **直達你條直播片**；
- iPhone 個金掣改做「官方連結」：一撳 iOS 自家機制（universal link）
  直開 Facebook App 果條片——Apple 官方路徑，最穩陣；
  冇裝 App 嘅客就自然落返網頁版條片，一舉兩得；
- Android 流程完全唔郁（你實測過係 work 嘅）；
- v2.2.16 醫 Samsung 彈窗閃走嘅邏輯全部保留。

【測試方法（新 URL，防 cache）】
1. 部署後 iPhone 打：
   https://redcode.red/live-go-v4.html?u=https%3A%2F%2Fwww.facebook.com%2Fwatch%2F%3Fv%3D28610528795252808
2. 預期：彈「在 Facebook 中開啟」→ 開啟 → **入 App 見到條片**（唔再係首頁）。
3. 跟手發個測試推播，撳通知 → 同上。

------------------------------------------------------------
② 順豐站點同步——成功定失敗，管理員而家睇到
------------------------------------------------------------
【你問嘅嘢，答你】
以前：每日自動同步**成功**會寫入後台「操作日誌」；
但如果**成次失敗**（例如順豐官網冇回應、DB 宕），齋寫伺服器內部 log，
**後台乜都睇唔到**——唔合格，今次補鑊。

【而家（三重保障）】
1. **站點管理頁頂多咗條「上次同步」狀態行**（長駐，唔係一閃即逝嘅 toast）：
   - 綠色「成功」／金色「部分失敗」／紅色「失敗」章
   - 時間＋新增/更新/停用/清重幾多個點
   - 失敗會寫明原因＋「站點清單維持現狀，聽日自動重試」
2. **操作日誌**（後台「日誌」頁）：每次同步——每日自動定管理員手撳、
   成功定失敗——全部有紀錄，仲有埋中文標籤「順豐站點每日同步」／
   「順豐站點即時同步」（以前係顯示英文代碼）。
3. **手撳同步失敗唔再扮成功**：以前就算全軍覆沒都會彈「新增 0、更新 0」，
   而家會照實彈紅色錯誤訊息，日誌都係寫「失敗」。

【驗收】
□ 後台 → 順豐站點管理：按鈕下面見到「上次同步」狀態行（成功綠章＋時間）
□ 撳「立即同步官方站點」：彈 toast 講成功/失敗，狀態行即時更新
□ 後台 → 日誌：搵到「順豐站點即時同步」紀錄，操作者係你個名

③ 部署
------------------------------------------------------------
1. zip 解壓，全個資料夾上傳覆蓋 GitHub repo（或 GitHub Desktop 拖入），
   push 後 Render 自動 build（約 3–13 分鐘）。
2. 資料庫唔使落指令（今次冇新欄位；設定鍵係自動寫入）。
3. JWT_SECRET / VAPID 等環境變數唔使郁。
4. WMS 今版冇改動，唔使上嘢（WMS 維持 v2.2.7）。
