■ 今次修咗咩
━━━━━━━━━━━━━━━━━━━━━━━━
【刪除會員失敗根治】（老闆報障：del 唔到會員，彈「Failed query: delete from users」）
・病因：會員一訂閱咗直播開播通知（推播裝置），資料庫 pushSubscriptions 表有外鍵連住
  users 表，而且冇設定自動連帶刪除 —— 所以刪會員嗰下被資料庫擋住。
・修復：刪會員時而家會連埋佢嘅推播裝置一齊清走，之後先刪會員本人。
・加碼防禦：就算日後有新表再連住會員，都唔會再彈 raw SQL 出嚟，
  會顯示友善提示「呢個會員仲有其他紀錄連住，暫時刪唔到，請通知技術員處理」。
・員工帳號刪除（帳號管理頁）同一個漏洞都一併修埋。

・刪除成功後 toast 會講清楚連帶清咗幾多嘢，例如：
  「已刪除會員（連埋 1 部推播裝置）」
  「已刪除會員（連埋 3 張訂單、2 部推播裝置）」
