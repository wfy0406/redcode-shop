■ 1. 首頁掣群第二輪高度美化（老闆指令：第2款式）
━━━━━━━━━━━━━━━━━━━━━━━━
・每粒掣改做「雙行標籤」：上行拉丁細字（SHOP NOW／FOLLOW US／LIVE REPLAY／LIVE ALERT），
  下行中文主標，即刻高級晒
・Hover 文字會向上滑入第二份標籤（slide-up swap，純 transform，GPU）
・兩粒 outline 掣尾加箭嘴，hover 會向前郁
・掣群背後加咗星光層（金粉四角星，AI 生成 cta-sparkles.png），慢慢漂移
・四粒等高對齊，排位更企理
・「已開啟通知」訂閱態：由無排版細字 → 變成同掣群同款嘅狀態 pill
  （呼吸粉點 + 金色 ✓ + LIVE ALERT ON 細字），唔再係醜文字
・全部動畫淨係 opacity + transform（GPU），唔會整慢客人電話；
  手機「減少動態效果」設定下全部自動停

■ 2. 直播重溫跳轉落點修正（老闆實測：差小小未到）
━━━━━━━━━━━━━━━━━━━━━━━━
・病因：頁面載入後直播區/圖片再 render，將 anchor 推離位（layout shift）
・修法：scroll 之後 900ms 同 1800ms 各做一次漂移檢查，偏超過 24px 就自動修正
・而家會啱啱好停喺「直播回顧」標題位

━━━━━━━━━━━━━━━━━━━━━━━━
■ 3. 直播回顧縮圖根治（老闆實測：仲係睇唔到）
━━━━━━━━━━━━━━━━━━━━━━━━
・病因：Facebook 封咗 Render 嘅伺服器 IP，自動摷圖長期失敗
・根治：後台「直播推送」每個已發送批次新增【上傳縮圖】掣 ——
  你喺 FB 睇直播時 cap 圖／用宣傳圖，上傳後官網直播位同回顧卡即刻顯示，保證有圖
・想唔用自訂圖，撳「還原自動摷圖」就得
・自動摷圖都加咗第三條路線（手機版 FB 頁），摷到機會大咗
・順手修埋後台縮圖診斷顯示 bug（摷到都話摷唔到）
