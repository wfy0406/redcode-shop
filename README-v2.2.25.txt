RedCode 網店 v2.2.25 更新說明
==============================

今次改咗咩？
------------
【註冊 + 結帳：順豐站點揀選整合】

1. 附近尋找一次過齊晒三類
   - 按「附近」而家會同時列出：順豐站、自提點（服務點／便利店）、智能櫃
   - 每個站點旁邊有顏色徽章標明類別：
     順豐站＝粉紅徽章、自提點＝金色徽章、智能櫃＝天藍徽章
   - 標題加咗「（順豐站／自提點／智能櫃一齊顯示）」提示

2. 揀咗邊型，類別自動跟
   - 客人喺附近清單揀咗智能櫃 → 取貨方式自動跳去「智能櫃」
   - 揀咗順豐站或自提點 → 自動跳去「順豐站／自提點」
   - 註冊頁同結帳頁都一樣玩法

3. 類別制改名
   - 「順豐站」制 →「順豐站／自提點」（因為自提點一直都歸呢類）
   - 結帳提示語同步更新

4. 客人唔揀附近，照樣可以自己輸入
   - 原有「自己輸入搵站」功能無郁過，照舊可用

點樣驗證（部署後）？
--------------------
1. 開註冊頁 → 取貨方式揀「順豐站／自提點」→ 按附近
   → 清單應該有晒三類站點，每個有顏色徽章
2. 揀一個智能櫃 → 上面類別制應該自動跳去「智能櫃」
3. 揀一個便利店／服務點 → 類別制自動跳／留喺「順豐站／自提點」
4. 結帳頁重複上面 1-3
5. 唔揀附近，用搜尋框自己打字搵站 → 正常揀到
