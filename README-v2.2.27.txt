RedCode 網店 v2.2.27 更新說明
==============================

今次有兩大項：直播播放器根治 ＋ 自取站點流程統一。

【一】直播播放器根治（首頁＋直播頁一齊好返）
--------------------------------------------
老闆實測回報（v2.2.26 之後）：
- Android Chrome：播到，但要撳先播，唔會一入自動播
- Samsung 瀏覽器：撳落去無反應
- iPhone：淨係「放大睇」睇到，就咁睇唔得

根因（講返實情）：
- Apple／Google／Samsung 三大手機瀏覽器一律封有聲自動播；
  FB 官方文件亦寫明嵌入播放器 autoplay「唔適用於流動裝置」
- 上版加嘅 muted=1 靜音參數，實測 FB 播放器照樣唔理
- 但「放大睇」度度都 work——因為佢係撳掣嗰下先新鮮載入播放器
  （瀏覽器規矩：用戶手勢入面載入嘅播放器，可以即刻有聲播）

修法（業界標準做法）：
- 首頁／直播頁直播區改做「真・直播縮圖海報」：
  而家縮圖係真嘅（Glo Glo 畫面），唔再係黑盒
- 海報中間大金播放掣（有動感光環），寫明「一撳即播・有聲 🔊」
- 客人撳一嘢 → 播放器即場載入即播，有聲！
  Samsung／iPhone／Chrome 全部行同一條成功路線，唔會再黑屏或撳唔郁
- 「放大睇」「去 Facebook 睇」照舊保留
- 直播重溫無郁過（本身就係撳 ▶ 即播有聲）

老實講：手機上「一入網頁就自動有聲播」係浏览器政策封死，
任何網站都做唔到；而家係「一撳即播有聲」，係手機上最好嘅體驗。

【二】自取站點流程統一（註冊＋結帳＋會員中心三處一致）
------------------------------------------------------
老闆指令：「一個按鈕搞掂」「會員中心都要同註冊一樣」
「結帳可以唔用預設，用客人果次想要嘅地址，下一次就會轉翻預設」

1. 自取一粒制：「送貨上門｜順豐站／自提點／智能櫃」
   - 唔再分兩粒制；揀咗邊型站點，類別自動歸類（順豐站/自提點→順豐站類、
     智能櫃→智能櫃類），站點卡有顏色徽章＋「已自動歸類」字樣
   - 揀咗智能櫃，自取制照樣亮起（有粉紅選中點），唔會跳走

2. 「用我位置搵最近」升做主角大金制
   - 揀咗自取即刻見到，唔使先撳搜尋框先出現
   - 想自己輸入嘅客人：搜尋框照舊喺下面，手動搵站無郁過

3. 定位唔準根治（第一次撳飄上環嘅問題）
   - 舊版攞第一次讀數就用——第一次多數係網絡/IP 粗略定位（成日飄中上環）
   - 新版連續收訊號，精度夠 80 米先收工，最多等 12 秒，攞最準嗰次
   - 如果誤差仲係大（>300 米），會提示客人「唔啱可以打地區名搵」

4. 結帳「今次唔用預設」保護
   - 客人一撳過取貨方式（包括撳送貨上門），預設帶入即刻停止，
     唔會再翻兜覆蓋客人今次嘅選擇
   - 會員預設本身永遠唔會被結帳改寫，下次入嚟照舊帶入預設

點樣驗證（部署後）？
--------------------
直播：
1. 直播期間 Android Chrome 入首頁 → 見到真縮圖海報＋金播放掣
2. 撳 ▶ → 即播有聲；Samsung 瀏覽器、iPhone Safari 同樣步驟 → 都播到
3. 直播頁（/live）頂部 → 一樣玩法
4. 「放大睇」→ 全屏照舊正常

自取流程（註冊／結帳／會員中心三處都試）：
5. 揀「順豐站／自提點／智能櫃」→ 大金制「用我位置搵最近」即刻見到
6. 撳定位 → 第一次就應該搵到真正附近（唔再飄上環）；
   三類站點混排有顏色徽章＋距離
7. 揀一個智能櫃 → 站點卡顯示「智能櫃」徽章＋「已自動歸類」，自取制照樣亮
8. 唔用定位，直接喺搜尋框打地區名（例如「屯門」）→ 手動搵站照舊正常
9. 結帳頁：有預設嘅會員入嚟自動帶入預設；撳「送貨上門」轉咗佢，
   碌落碌上／再入都唔會彈返去預設；下次新結帳又會帶入預設
