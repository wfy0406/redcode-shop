==============================

包含 v2.2.27 全部內容（直播一撳即播＋自取流程統一），再加：

【「用我位置搵最近」加 GPS 雷達 icon（四處一致）】

全站同一套設計。

【會員中心「未揀站點」摘要修正】
--------------------------------
老闆回報：「註冊已選咗預設站點，但會員中心寫未選，按編輯又有選到」
根因：註冊淨係存咗站點 ID，冇存站名快照（pickupPoint）；
會員中心摘要係用站名快照顯示嘅，所以出「（未揀站點）」；
編輯畫面用 ID 查所以正常。
修正：
- 註冊而家連站名快照一齊存（新會員即刻正常）
- 會員中心摘要：冇快照就用 ID 反查站名補位（舊會員都即刻正常）
- 編輯儲存時順手補寫返快照，一勞永逸

【直播海報縮圖壞圖修正】
----------------------
老闆回報：「主頁直播同直播頁之前載入前會有縮圖，依家無咗，縮圖壞咗」

根因：
- 縮圖係後端經 /api/live-thumb/:id 代摷 FB 嘅圖；FB 對 server IP 時好時壞，
  今場直播摷唔到 → 圖回 404
- 舊版縮圖只係播放器載入嗰秒嘅背景，壞咗都被 iframe 冚住，所以一直見唔到；
  v2.2.27 縮圖升做海報主角，壞圖就現形（broken icon＋黑底）

修正：
- 縮圖載入失敗 → 即刻跌落品牌紅金光暈海報（LIVE badge＋金播放掣照舊），
  永遠唔會再出現 broken 圖示
- 換場直播會自動重試新縮圖（唔會一壞壞一世）
- 播放器載入背景同一邏輯

提提你：如果想今場直播即刻有靚縮圖，可以用 v2.2.23 嘅手動上傳：
後台 → 直播推播 → 嗰場直播嘅「上傳縮圖」→ 揀張相，即刻生效，
唔使等 FB 摷圖。

點樣驗證（部署後）？
--------------------
1. 首頁直播區：縮圖正常就見真縮圖；縮圖摷唔到就見紅金光暈海報，
   兩者都唔會有 broken 圖示
2. 直播頁（/live）頂部：同上
3. 撳 ▶ → 即播有聲（v2.2.27 路線不變）
4. 後台上傳縮圖 → 首頁海報即刻變返真縮圖
