改咗乜：GPS 定位「第一次必死、過陣先得」
────────────────────────────────────────

【老闆實測現象】一開始撳「用我而家嘅位置」話「未能取得你嘅位置」，
試完地址搜尋再撳返定位又得。

【原因】唔係 bug 咁簡單，係手機 GPS 特性：
・手機 GPS 冷啟動要十幾廿秒先鎖到衞星（室內仲耐），
  舊代碼一刀切 10 秒 timeout → 第一次梗係死；
・死完之後瀏覽器／系統有咗暖身位置快取，第二次撳即刻有 → 「突然得返」。
・舊錯誤訊息將「拒絕授權／收唔到訊號／逾時」三種情況冚埋一舊講，誤導。

【點修】兩段式定位＋分得清嘅錯誤提示：
・第一段：network/Wi-Fi 快速定位（唔等衞星，通常 1–2 秒有，
  誤差幾十米，搵順豐站完全夠用）；准用 5 分鐘內快取。
・第二段：第一段逾時先自動開 GPS 高精度重試（25 秒）——用戶唔使再撳。
・錯誤訊息按情況分開：
  - 拒絕授權 → 教埋點樣開返（地址欄鎖形 icon → 權限 → 位置 → 允許）
  - 收唔到訊號 → 提示行近窗邊／出面
  - 逾時 → 提多試一次或打地址
・「打地址搵最近站點」永遠係可靠後備（政府 ALS 雙語地址庫），兩條路互補。
