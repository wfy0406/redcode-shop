====================================================
redcode-shop v2.2.40 —— 首頁 CTA 閃石框位置/大細修復
====================================================

【你見到嘅問題】
電腦版首頁「即睇商品／追蹤 Facebook／直播重溫」嗰排掣後面，
閃石變咗一個正方形框，位置同大細都怪。

【原因】
閃石圖（cta-sparkles.png）本身係正方形，設計係四角有閃石、中間留空，
靠佢哋圍住掣。手機版掣係 2×2 排列、盒近正方形，所以一直靚。
電腦版掣變咗橫排一行、盒變橫長——但 CSS 用 contain（等比縮放入盒），
正方形縮到只剩正中一個細正方形，閃石框就缩晒喺唔啱嘅位置。

【修復】
我照原圖四角嘅閃石群，砌咗張闊版星塵圖（cta-sparkles-wide.png），
電腦版（640px 起）自動改用佢，直接拉滿成個盒：
閃石永遠貼住盒四角，中間留空俾掣——咩屏幕闊度都啱位。
手機版維持用原圖，完全唔變。飄移動畫照舊。

【今次郁咗邊啲檔】（兩個，其他一個字冇郁）
  src/pages/Home.tsx              （CTA 星塵層 CSS，加咗電腦版媒體查詢）
  public/cta-sparkles-wide.png    （新檔——闊版星塵圖，約 190KB）
冇 DB 改動，冇新環境變數。

【部署方法（同平時一樣，你自己 push）】
  1. 解壓，兩個檔照路徑冚過／放入 repo
  2. git add / commit / push 去 master
  3. Render 自己 build 同 deploy

【部署後點驗收】
  1. 電腦開 redcode.red 首頁，睇 CTA 掣嗰排：
     閃石應該喺掣嘅左右兩邊角落圍住佢哋，唔再係中間一個正方形框
  2. 手機開同一版：閃石維持之前咁圍住 2×2 掣組，冇變
  3. 窗口拉闊拉窄試下：閃石都會跟住盒四角，唔會再離位
