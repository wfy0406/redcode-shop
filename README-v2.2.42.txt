redcode-shop v2.2.42 —— 手機選單「直播場次」收唔埋修復
====================================================

【你見到嘅問題】
手機選單「直播場次」嘅月份（例如 2026年9月）撳極都收唔埋，
一直展開住。

【原因】
原本有個「自動開最新月」嘅設定：數據一返嚟就幫客人展開最新嗰個月。
但寫漏咗——佢一見到「冇月份展開緊」就自動開返。所以你一撳收埋，
佢即刻又幫你開返，永遠收唔到。
（電腦版商品 dropdown 入面嘅直播場次係同一份設定，同樣受影響，一併修好）

【修復】
「自動開最新月」改做淨係第一次入數據嗰下先做一次；
之後你手動收埋就真收埋，唔會再彈返出嚟。
（檔：src/components/Navbar.tsx，一個檔）

【部署方法（同平時一樣，你自己 push）】
  1. 解壓，Navbar.tsx 冚過 repo 入面嗰個
  2. git add / commit / push 去 master
  3. Render 自己 build 同 deploy

【部署後點驗收】
  1. 手機開選單 → 商品 → 直播場次：第一次開應該自動展開最新月（照舊）
  2. 撳「2026年9月」嗰行：月份應該收得埋，箭嘴轉返向下
  3. 再撳一次：重新展開，箭嘴轉向上
  4. 電腦版 hover「商品」dropdown 入面嘅月份一樣收開自如

【順帶一提】
截圖得「2026年9月 28日第1場」係正常——呢個區淨係列出有歸入商品嘅場次
（後台商品嗰個「📺 直播場次商品」設定）；10月嗰兩場未歸商品就唔會出現。
