====================================================
redcode-shop v2.2.43 —— 後台新增「綁定手機」清單
====================================================

【你嘅要求】
後台整個綁定手機數清單，要有：客戶名、幾時綁定、裝置廠牌、用咩瀏覽器。

【而家有咗】
官網後台左邊 menu 多咗一項「綁定手機」（喺「直播推送」下面），入去即見：
  · 概要：總共幾多部裝置綁定咗、覆蓋幾多位客戶
  · 每部裝置一行：客戶名＋電話／裝置廠牌（Apple iPhone、Samsung、Xiaomi…）／
    瀏覽器（Chrome、Safari、Edge、Facebook 內置、微信內置…）／
    綁定時間／最近推送時間
  · 搜尋框：輸入客戶名、電話或 email 即時篩
  · 手機睇係逐部一卡，電腦睇係表格
清單唯讀；訂閱嘅敏感內容（endpoint／密鑰）後端一如既往唔會回前端。

【技術備註】
  · 綁定時本來就有存 userAgent，所以舊綁定都即刻顯示到，唔使等客人重新綁
  · 冇 DB 改動、冇新環境變數
  · 會員詳情卡入面嘅「直播推送」段同 WMS 嗰邊完全冇郁

【今次郁咗邊啲檔】（三個）
  api/membersRouter.ts                        （新 API：adminListPushDevices ＋ UA 廠牌/瀏覽器分析）
  src/components/admin/BoundDeviceList.tsx    （新檔：清單頁面）
  src/pages/Admin.tsx                         （左 menu 加「綁定手機」一項）

【部署方法（同平時一樣，你自己 push）】
  1. 解壓，三個檔照路徑冚過／放入 repo
  2. git add / commit / push 去 master
  3. Render 自己 build 同 deploy

【部署後點驗收】
  1. 官網後台左 menu 撳「綁定手機」：應該見到已訂閱客人嘅裝置清單，
     每行有名、廠牌、瀏覽器、綁定時間
  2. 搜尋框打個客戶名：即時篩到佢嘅機
  3. 電話開同一版：變咗一卡卡，資料齊
