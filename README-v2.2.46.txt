RedCode 官網 v2.2.46 —— 直播抽獎大輪盤
==================================================

【今次更新內容】
1. 後台新增「直播抽獎」頁（導覽列禮物 icon），只有主管＋管理員睇到入到。
2. 華麗大輪盤：直播畀客睇，金色輪圈＋鉚釘、煙花、6 秒減速轉動，中間彈出中獎客人名（大字滾動效果）。
3. 獎品管理：可以上傳圖片、填貨號（SKU）、價錢，隨時加／減獎品；已抽出嘅獎品會標「已抽出」，抽晒就冇得再抽。
4. 參加名單剔選：本月消費／累積消費／消費滿 $X／官網會員名單／買過指定官網產品／已綁定推送客人，可任意組合，會即時預覽人數同名單。
5. 公平規則：同一個客人同一日只會中一次；抽獎喺 server 用密碼學隨機抽，名單顯示上限唔會影響真池。
6. 每件獎品抽完可以揀：「冇問題，抽下一件」／「特別重抽」（舊中獎作廢，由同一批名單重抽，會留紀錄）／「取消中獎」。
7. 中獎紀錄：按日摺疊，展開睇到當日邊個中咗咩、狀態（待回覆／已確認／已婉拒／已取消），未飛 WMS 嘅單可以隨時取消，客人即刻唔會再見到中獎彈窗。
8. 客人端：登入（或已登入緊）會彈中獎方塊——煙花＋小精靈 gloglo 飛入＋獎品卡，按鈕「多謝，請寄送」／「唔要」／「遲啲先揀」。
9. 揀寄送：有預設順豐站／自提點／智能櫃／送貨地址就一撳用預設；冇就用返結帳嗰套（GPS 搵最近站點＋分類篩選＋地址搜尋）。
10. 確認後自動出 0 元訂單飛去 WMS 等審批：備註「官網訂單・包郵・直播抽獎中獎商品」，價錢 0，訂單日期＝抽獎日，場次＝0，商品圖一齊過去；獎品有 SKU 會對返現有產品，冇就自動起一件隱藏商品。
11. 我嘅訂單：中獎訂單有金色中獎框，寫明中獎商品、抽獎日期、0 元包郵。
12. 中獎即刻寄恭喜 email（中獎日期／獎品／圖片／價錢）＋ 推送通知。

【部署步驟】
1. 解壓後照路徑覆蓋 repo 對應檔案。
2. 推送部署後，server 啟動時會自動起 luckyPrizes / luckyDraws 兩張表（boot-migrate，唔使手動跑 SQL）。
3. 建議抽獎前先入後台「直播抽獎」加幾件獎品試玩。

【老實備註】
- 已確認中獎（已飛 WMS）嘅單如果要取消，要喺 WMS 嗰邊處理，後台取消制會提示你。
- 中獎商品嘅庫存唔會自動扣（0 元單），如需扣庫存請喺 WMS 處理。
- 抽獎頁建議用電腦開（直播畫面），手機都用到但輪盤會縮細。
