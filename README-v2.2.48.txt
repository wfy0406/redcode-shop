RedCode 官網 v2.2.48 —— 抽獎：自訂名單＋WMS 綠燈＋刪除紀錄
==================================================

【重要】呢個 zip 入面嘅 db/schema.ts、api/boot-migrate.ts、api/luckyDrawRouter.ts、
src/components/admin/LuckyDrawPanel.tsx 係最終版，會覆蓋 v2.2.46 嗰四個檔
（已包埋 v2.2.46 之後發現嘅兩個修正：預覽名單 runtime 錯誤、澳門站單 region）。
三個 zip 照次序覆蓋就得：v2.2.46 → v2.2.47 → v2.2.48。

【今次更新內容】
1. 抽獎名單加「自訂名單」模式（同「會員條件名單」並排 tab 切換）：
   - 創建名單：名單名＋客人名逐個輸入／批量貼上（一行一個、逗號、空格、頓號都分到）；
   - 亦可以「由官網會員加入」：搜會員名或電話，點擊加入（金邊 ✦ chip 同手打名分得清清楚楚）；
   - 名單可以刪除；揀好名單即抽，輪盤照常轉。
2. 中獎後台即場揀：確定／取消／重抽。
   - 手打名中獎：撳「✓ 確定中獎」即刻出 0 元訂單飛 WMS 審批——客人名＝輸入名、獎品按貨號、
     價錢 0、備註「官網訂單・包郵・直播抽獎中獎商品」，同正常訂貨格式一樣；
   - 官網會員中獎：照舊彈中獎通知（彈窗＋email＋推送），由佢自己登入揀地址寄送，
     後台會見到「等佢自己揀地址」提示，唔使出單制；
   - 重抽由同一份名單再抽；取消即場作廢。
3. 一日一個名中一次（按名計）；官網會員嗰邊照舊一日一個帳號一次。
4. 剩餘獎品計數：抽獎頁頂部「剩餘獎品 X 件（總共 Y 件）」，每抽完一件即場減；取消/刪除會返返嚟。
5. 中獎紀錄綠燈（老闆指定）：WMS 審批通過嘅中獎單，紀錄會用綠色邊框住「● 已確認」；
   未批嘅顯示「● WMS 審批中」（琥珀色）；待客人回覆／待確定／已婉拒／已取消照舊。
   會員抽獎同自訂名單抽獎一視同仁——審批過咗就有綠燈，結案。
6. 管理員可以刪除該場抽獎紀錄：紀錄每行最右「刪除」（淨係管理員睇到）；
   未審批嘅 0 元訂單會一併取消；已審批／已出貨嘅單唔俾刪，要去 WMS 處理。
   刪除後獎品會返返入剩餘池。
7. 會員管理名單唔會見到自訂名單嘅手打名（佢哋唔係官網會員，系統用 DRAW# 影子帳號起單，已隔離）。
