【redcode-shop v2.2.7 點放】（老闆專用，跟住做就得）

呢版修咗兩件事：
1) 直播回顧撳 ▶ 彈「影片不存在」
2) 結帳頁見唔到自己預設嘅順豐站／服務點

────────────────────────
一、點解會「影片不存在」？
Facebook 個嵌入播放器只認得「有數字 ID 嘅影片永久連結」。
推送時入嘅連結如果係專頁首頁、live 連結或者短鏈，
播放器認唔到就會話影片不存在。

而家做法：
· 連結認到影片 ID → 照舊原位播，唔離開官網都睇到
· 認唔到 → 撳 ▶ 直接彈去 Facebook app 睇（有裝 app 開 app，
  冇裝開網頁版），唔會再出「影片不存在」

────────────────────────
二、結帳頁預設順豐站／服務點修復
之前用「服務點」做預設嘅會員，結帳頁會認唔返個站：
· 揀站列表而家「順豐站」方式會同時包埋「服務點」
· 預設指標斷咗嘅，結帳時會用站名即場認親，靜音修返會員資料
· 開機會自動再跑一次修復（V2），舊會員唔使郁手

────────────────────────
三、點放（同之前一樣）
1. 去 GitHub redcode-shop 倉，上傳 zip 入面全部檔案（覆蓋）
2. Render 會自動重新 build，等佢轉返綠色 Live
3. 驗收：
   · 直播頁撳回顧 ▶：認到嘅會播片；認唔到會彈去 FB app
   · 結帳頁：順豐站／服務點預設會自動帶出

注意：WMS 唔使郁，呢版淨係官網。
