呢版修咗三件事：
1) 直播進行中都可以官網原位睇片（之前淨係得「去 Facebook 睇」）
2) 直播回顧／直播頁認 share 短鏈叻咗——login 牆擋都識摷返條片
3) 推播撳入去開唔到 FB app——兩層修復

────────────────────────
一、直播／回顧官網播片
· 後台而家會自動解鏈：share/v/、fb.watch 短鏈 → 正式影片地址
· 就算 Facebook 彈 login 牆，都會由牆入面摷返影片 ID
· 認到 → 撳 ▶ 官網原位播；認唔到 → 撳 ▶ 彈去 FB app（唔會再出「影片不存在」）
· 直播進行中嗰張大卡一樣：認到就可以官網直接睇直播

────────────────────────
二、推播撳入去開 FB app
· 推送嗰刻官網會先將短鏈解做正式 /watch 連結先派出——
  FB app 一定認得呢款
· 跳板頁改用「fb 專用通道」開 app：裝咗 app 就一定開到，
  唔再受連結款式影響；冇裝 app 自動落網頁版

────────────────────────
三、後台新嘢：連結檢查
推送頁入完 Facebook 網址，等 1 秒會話你知：
· ✓ 金句：官網播到，放心推送
· ⚠️ 粉紅字：官網認唔到，建議換條片嘅長連結（入去條片複製地址欄）

────────────────────────
四、點放（同之前一樣）
1. GitHub redcode-shop 倉上傳 zip 全部檔案（覆蓋）
2. Render 等轉綠色 Live
3. 驗收：
   · 推送頁入條 share 連結 → 睇到 ✓ 或 ⚠️
   · 手機撳推播 → 有裝 FB 會開 app
   · 直播頁／首頁直播區撳 ▶ → 官網播到（認到嘅話）

注意：WMS 唔使郁，呢版淨係官網。
