【redcode-shop v2.2.58】直播推送欄位手機版面修復
================================================

老闆報料：官網後台「直播推送」版，手機睇啲欄位彈晒出卡片右邊，仲要左右碌先得。

病因（已用無頭 Chrome 重現＋逐元素量度證實）：
- 「通知預覽」卡入面嗰條 FB 直播網址用咗 truncate（唔斷行＋省略號）。
- 嗰段 <p> 係 block 元素，唔係 flex item —— 上層嘅 min-w-0 保護傳唔到落去。
- FB 長網址唔斷行，佢嘅「最小內容闊度」有成 400 幾 px；手機單欄 grid 嗰陣，
  軌道闊度俾呢條網址吹爆，成個表單（日期／場次／網址／剔選卡／發送掣）
  全部跟住超出卡片右邊，頁面底部仲出埋橫向 scrollbar。
- 電腦／大芒（≥1024px 兩欄）冇事，所以一直冇人發現；Fold 細芒／手機就中晒。

修復（得兩行 class，零結構改動）：
- src/components/admin/LivePushPanel.tsx
  1) 表單嗰欄 div 加 min-w-0（line 517 附近，space-y-4 前面）
  2) 預覽嗰欄 div 加 min-w-0（line 698 附近，原本無 class）
  原理：grid item 加 min-w-0 之後，自動最小尺寸歸零，軌道永遠唔會超過卡片；
  網址照樣單行省略號顯示，外觀完全冇變。

驗證（無頭 Chrome，真實 DOM 結構 1:1 重現）：
- 修復前：352px 闊度重現到一模一樣嘅溢出（form 卡內容吹脹 83px，頁面橫移 38px）
- 修復後：320 / 352 / 500 / 645 / 800 / 1100 / 1400 px 全部寬度掃晒——
  手機單欄冇溢出、冇頁面橫scroll；≥1024px 兩欄排版正常；
  場次 pills 正常 wrap 做兩行；發送紀錄表格照樣內置橫scroll。
- esbuild 語法檢查通過。

推咗之後唔使額外設定，前台 build 出嚟即生效。
