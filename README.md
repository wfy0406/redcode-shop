## 今次做咗咩

1. **Google 登入後「移入會員訂單」接得返**（你報：「按左 GOOGLE 登入，登入完變左空既我的訂單」）
   - 起因：由 email 魔法連結入去嘅訪客單，全程冇填過電話，所以撳「移入會員訂單」時記低嘅資料冇電話，登入返嚟接唔返；加埋 Google 登入喺手機會用「跳轉模式」，原本記住嘅返回位置會丟失，變咗落去空嘅「我的訂單」。
   - 而家：
     - 查單 API 會連訪客電話一齊返（呢個 payload 本身要 token／電話核實先拎到，安全）；
     - 撳「移入會員訂單」記低單號＋電話（**永遠唔記 token**）；
     - 登入頁（密碼登入＋Google 登入）如果見到有未接嘅移入流程，登入成功會直接去「我嘅訂單」自動彈返確認框，唔再跌落空頁；
     - 訪客付款頁嘅「移入」掣都補埋電話，兩條路徑都接得返。

2. **WMS 整單取消，官網同步轉「已取消」**（msg85 第 1 點：「WMS 已經變左已取消，官網查單仲寫住只取消左一件」）
   - 起因：RC202610107171 嗰件 B1特別款，一件出咗貨一件取消咗；WMS 整單取消嘅回調嚟到，官網舊邏輯係「已出貨嘅貨唔准再郁」，所以出咗貨嗰件 skip 咗，張單永遠停喺「已寄出＋取消咗 1 件」。
   - 而家：**全數取消**嘅話，已出貨嘅件都會跟住取消（官網即轉「已取消」）；但「部分取消」仲係唔准郁已出貨嘅件（包裹已計數，抽唔到返嚟）。
   - 庫存：已出貨嘅件取消**唔會**回補庫存（貨已離倉）；未出貨嘅件照舊回補。
   - ⚠️ **舊單補救（RC202610107171）**：部署咗之後，去 WMS 官網中心搵呢張單，再撳一次「刪除全單」填原因 —— 回調會再嚟一次，官網就會轉「已取消」。（注意：會再寄一封貨品取消信畀客人，原因佢會睇到，測試單建議寫「系統測試」之類。）

3. **訪客查單顯示退款狀態**（msg85 第 3 點：「如果已退款，官網都要寫埋已退款，跟WMS退款狀態」）
   - 訪客查單頁而家同會員「我的訂單」一樣，跟 WMS 退款流程顯示 badge：
     - ⏳ 退款審批中
     - ❌ 已取消 · 已退款（成張卡灰化，同 WMS 灰卡呼應）
     - ❌ 已取消 · 人手退款處理中（同樣灰化）
     - ⚠️ 退款失敗 · 請聯絡客服
   - 冇退款嘅單乜都唔會多。
