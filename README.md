## 今次做咗咩

1. **訪客單「移入會員訂單」登入後唔再消失**（msg76c / msg79e）
   - 之前：訪客單撳「移入會員訂單」→ 彈去登入 → 登入返嚟，嗰張單唔見咗，要客人自己搵返 email 連結。
   - 而家：撳掣嗰刻會記低單號＋電話（**永遠唔記 token**），登入返嚟「我嘅訂單」會自動重新查單、拎新 token，直接彈返確認框出嚟，一撳就移入。
   - 失敗（例如資料過期）會出紅色提示條，統一訊息，唔會講係邊步錯（防枚舉），客人可以撳 ✕ 關走。

2. **移入嘅訪客單計入全年消費 / VIP 級別**（msg76c / msg79e）
   - 訪客單一移入會員，後台即刻重計嗰個會員嘅全年消費同 VIP 級別。
   - 包括「已經移入過」嘅情況都會補計，唔會再有「移入咗但 VIP 冇郁」嘅漏洞。

3. **順豐追蹤連結統一香港版**（msg81）
   - 官網嘅順豐查單連結（訪客單頁、會員訂單頁、電子單據、出貨 email）之前用咗內地簡中版網址，香港客開會被彈去簡中頁。
   - 而家全部統一做香港繁中版，同 WMS 嗰邊一致。
   - **順豐單號顯示功能本身其實 v2.4.0 已經有**：只要 WMS 出貨嗰陣入咗順豐單號，訪客單、會員訂單頁、單據、email 四個位都會顯示單號＋追蹤掣。
   - ⚠️ 留意：如果而家網站見唔到單號，好大機會係 **Render 未 deploy 最新 master，或者電話 cache 咗舊版**——舊版嘅狀態係寫「已出貨」，新版寫「已寄出」。請確認 Render 已經 deploy 最新 master，然後強制刷新（或者開無痕試）。
   - ⚠️ 另外：v2.4.0 之前已經出咗貨嘅歷史單，當時冇批次紀錄，所以**唔會返轉頭顯示單號**；之後出貨嘅單就一定有。

4. **部分取消嘅單，出貨信同訂單頁講清楚**（msg83，NEW）
   - 例如 RC202610107171（B1特別款 ×2 取消咗 1 件）：
     - **出貨 email**：之前寫「全部貨品都寄出晒（共 1 件）」，冇提取消；而家寫「**已寄出晒（共 1 件，已取消商品除外）**」，資料盒多一行「取消貨品：取消咗 1 件（退款安排見取消通知信）」；部分寄出嘅信都會加「另有 N 件已取消」。
     - **會員「我嘅訂單」**：已寄出嘅單如果有取消件，狀態下多一行綠字「**取消咗 1 件，其餘已寄出晒（已取消商品除外）**」；部分寄出嘅 headline 一樣會補「（另有 N 件已取消）」。
     - **訪客查單頁**：同一句，一樣有。
     - （WMS 官網中心嘅 badge 喺 WMS 嗰個包處理。）

5. **Email 手機排版修復**（msg83，NEW）
   - 你截圖嗰封出貨信，喺手機 Gmail 度「訂單編號」「寄出」同商品名壓到一個字一行（直排）。
   - 原因係 Gmail 手機版會放大字體兼重排表格；而家資料盒嘅標籤格鎖死唔換行、商品名嗰格攞晒剩餘闊度，手機睇返正常排版。
   - 呢個修復對**所有系統信**生效（出貨信、取消信、確認信……佢哋共用同一套表格組件）。

## 部署步驟

1. 解壓，將 9 個檔案按路徑覆蓋落 repo。
2. `git add -A && git commit && push` 去 master。
3. Render 自動 build 同 deploy。
4. 部署完之後建議即場試：
   - 開一張測試訪客單 → 撳「移入會員訂單」→ 登入 → 應該自動彈確認框
   - 移入之後睇會員嘅全年消費有冇即時更新
   - 搵 RC202610107171 睇會員/訪客訂單頁有冇「取消咗 1 件，其餘已寄出晒」嗰行字
   - 之後出貨嘅部分取消單，封信會寫「已取消商品除外」＋手機睇排版正常
