redcode-shop v2.2.56 — 輪盤深度美化 ＋ 場次手動歸檔
=====================================================

今次包咗兩單老闆指令：
1. 「輪盤深度美化繼續做」
2. 「場次分組如果未抽晒，管理員要可以手動將獎品場次變歷史場次」

-----------------------------------------------------
一、場次手動歸檔（新功能）
-----------------------------------------------------
- 「獎品管理」個場次下拉隔籬多咗粒掣：
  · 未抽場次 → 顯示「放入歷史」
  · 已歸檔場次 → 顯示「放返未抽」（隨時還原）
- 揀咗「放入歷史」之後，場次下拉嘅「歷史場次」分組度會見到佢，
  後綴寫明（已歸檔）；自動抽晒嘅場次後綴係（已抽晒），兩隻字睇得返邊個係手動邊個係自動。
- 歸檔只係顯示分組：獎品照舊抽得、件數照扣，唔影響任何抽獎邏輯。
- 限管理員（admin）先見到粒掣；「未分場」唔准歸檔。
- 自動已抽晒嘅場次唔使歸檔都會喺歷史組，所以粒掣喺自動歷史場次會收埋（除非佢本身已手動歸檔，就可以放返）。
- 歸檔／放返都有審計紀錄（luckyDraw.archiveSession / unarchiveSession）。

-----------------------------------------------------
二、輪盤深度美化
-----------------------------------------------------
- 扇面：每格金屬漸變＋高速轉嗰陣有鬼影拖尾（速度越快越明顯）。
- 外圈：加厚金邊（四段金色漸變）＋兩條暗坑紋，似實物輪盤。
- 走馬燈：28 粒燈泡圍住外圈，閒置慢慢輪住著、轉嗰陣追住速度閃，
  著嗰粒有光暈（radial glow）＋白熱燈芯。
- 盤心：雙金環＋12 粒旋轉金鑽做裝飾；中心 hub 多咗圈旋轉金光（conic sheen）
  同呼吸式外發光（glowPulse）。
- 指針：SVG 金色漸變指針，轉嗰陣會左右輕微搖擺（pointerWobble）。
- 煙花：中獎煙花升級——有升空軌跡、衝擊波圓環、三段延時爆發（0/240/500ms），
  管理員輪盤同客人 PrizeWinModal 兩邊一致。
- 結果卡：金色 shimmer 掃過效果（掃完即走，唔會殘留金線）。
- 全部動畫只用 transform/opacity（GPU），冇郁 layout；DOM 層次用 DOM order 唔係 z-index。

-----------------------------------------------------
三、reduced-motion（系統「減少動態效果」）行為
-----------------------------------------------------
- 閒置走馬燈、hub 金光、指針搖擺、shimmer 全部停。
- 煙花完全唔放（兩邊一致），輪盤照舊可以抽，結果照舊彈出。

-----------------------------------------------------
四、資料庫 migration（自動跑，唔使人手）
-----------------------------------------------------
boot 嗰陣自動執行：
- ALTER TABLE "luckyDrawSessions" ADD COLUMN IF NOT EXISTS "archivedAt" timestamp;
- ALTER TABLE "luckyDrawSessions" ADD COLUMN IF NOT EXISTS "archivedByName" varchar(128);
舊資料完全唔受影響（新欄位預設 NULL＝未歸檔）。
