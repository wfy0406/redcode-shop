刪除直播回顧 HTTP 500 修正（2026-10-08）
=========================================

【問題】
WMS 官網中心撳「🗑 刪除回顧」炒「官網回應 HTTP 500」；
官網後台推送頁刪除同一筆都會 500。

【原因】（同你喺 Facebook 刪咗條片完全無關！）
資料庫入面，每場發送過嘅推送批次（pushCampaigns）下面掛住逐部裝置嘅
發送紀錄（pushDeliveries），而條外鍵冇設 cascade——
即係話：發過通知嘅批次，只要仲有發送紀錄指住佢，資料庫就唔准刪，
程式冇接住呢個情況，所以炒 500。
你喺 Facebook 刪片，官網淨係儲咗條網址做文字，唔影響資料庫。

【修復】（兩條刪除路徑都改咗）
刪除批次之前，先刪晒佢下面嘅發送紀錄，再刪批次本身：
1. api/pushRouter.ts  → 官網後台「推送」頁嘅刪除
2. api/wmsLivePush.ts → WMS 官網中心「直播推送」嘅刪除
唔使做資料庫 migration，淨係程式邏輯改動，零遷移風險。

【部署】
照常推 main → Render auto-deploy 約 30–40 分鐘。
因為係純後台改動，前端版本號唔會變，等夠時間先好試。

【驗證】
部署完之後：
1. WMS → 官網中心 → 直播推送 → 撳「🗑 刪除回顧」→ 應該顯示成功
2. 官網後台 → 推送 → 刪除同一場回顧 → 一樣成功
3. 直播頁回顧清單即時冇咗嗰場

【檔案清單】（Desktop 應該見到 2 個檔案改動）
- api/pushRouter.ts
- api/wmsLivePush.ts
