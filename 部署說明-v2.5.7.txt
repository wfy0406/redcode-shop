RedCode 官網 v2.5.7 補丁：搜尋加貨號 sku＋唔分大小寫
====================================================

【做咗咩】
官網 products.list 嘅關鍵字搜尋，之前淨係搵「品名＋描述」而且分大小寫 ——
所以打貨號（例如 LU8）永遠搵唔到，打 lu8 又搵唔到 LU8。
依家：
  ① 搜尋範圍加埋「貨號 sku」—— 打 LU8 直接搵到件貨
  ② like → ilike —— 品名／描述／貨號三個欄位都唔分大小寫
     （LU8 / lu8 / Lu8 一樣搵到）

【點解要咁做】
老闆 2026-10-24 報案：「上架商品依家邊有lu8？你自己睇下啦」——
查實官網依家真係冇 LU8 上架中（已用 API 核實，現役 26 件貨入面冇 LU8），
但官網搜尋連貨號都唔搵，令人以為「搜尋壞咗／有嘢收埋咗」。
補完之後，貨號一搜即知有冇，唔使靠估。

【覆蓋方法（同之前補丁一樣）】
1. 解壓呢個 zip，入面得兩個檔：
     api/productsRouter.ts   ← 補丁後嘅完整檔案（直接覆蓋官網 repo 同名檔）
     本說明.txt
2. 用 GitHub Desktop 開 redcode-shop repo → Pull 咗先 →
   將 api/productsRouter.ts 覆蓋 repo 入面 api/productsRouter.ts →
   commit（訊息建議：v2.5.7 搜尋加sku+不分大小寫）→ push。
3. Render 自動 rebuild（約 2-4 分鐘），等部署完成。

【驗證（push 完 rebuild 好之後）】
‧ 官網搜尋打「LU8」→ 而家 LU8 冇上架中貨，應該顯示搵唔到（呢個係事實）；
  但打任何「上架中」貨嘅貨號（例如現役貨號）會直接搵到件貨。
‧ 打品名細楷（例如「top」）一樣搵到大細楷混合嘅品名。
